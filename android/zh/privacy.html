听播 Android 隐私政策

本政策由 Google Play 开发者 VoxaDeck 为听播 Android 应用发布。

生效日期：2026 年 9 月 15 日

本政策说明 Tingbo Android 应用如何处理您的演示文稿、演讲备注及相关数据。Tingbo 用于导入演示文稿、查看幻灯片、编辑备注、朗读备注和导出文件。应用面向 13 岁及以上用户，无需创建 Tingbo 账号，不展示广告，不提供应用内购买。

1. 您的文稿与设备内数据

当您通过 Android 文件选择器导入文稿时，Tingbo 会读取您选择的文件，并在应用存储中保存用于使用该功能的副本。数据可能包括原文件、幻灯片图片、文稿名称、导入时间、演讲备注、您对备注的编辑以及文稿历史。应用也会保存播放引导等本地偏好，以及朗读音频和导出操作所需的缓存。

这些数据用于打开和呈现文稿、朗读、编辑、恢复历史及导出。导出文件会保存到您通过系统文件选择器指定的位置；该位置可能由设备或您选择的云端文件服务管理。

2. 在线格式转换

当导入的文稿需要在线转换或渲染时，Tingbo 会上传整份所选文稿，其中可能包含幻灯片中的文字、图片、演讲备注及文件内的其他内容。转换不是只上传文件名称或当前一页。接收数据的服务包括 Cloudflare 和 CloudConvert，用途是将文件转换为应用能够读取或显示的格式并返回结果。

Android 版的原文件经 Cloudflare Worker 转发至 CloudConvert；转换结果也经 Worker 返回应用。不要在未取得相关权利的情况下上传其他人的文稿或个人信息。

CloudConvert 会暂存文件；其 API 文档说明任务及数据在任务结束后 24 小时自动删除。供应商日志与文稿分开留存：CloudConvert 的政策列明 IP 地址、User-Agent、访问时间等日志可保留 180 天，也可能处理基于 IP 的大致位置及服务统计。详情见 CloudConvert 隐私政策和 Jobs API 文档。

Cloudflare 在提供网络和转换接口服务时可能处理 IP 地址、路由、请求和系统信息；其数据处理说明见 Cloudflare 隐私政策。供应商使用的处理地点可能位于您所在国家或地区之外，具体取决于其服务配置及路由。

3. Android 文字转语音

Tingbo 将备注文本交给您设备上启用的 Android 文字转语音引擎来生成朗读音频。应用可能在文稿打开、翻页或备注更新时提前生成当前页及相邻页的音频，因此引擎处理文本不一定要等到您点击播放才开始。

语音处理是否完全在设备上完成，取决于您使用的引擎、语音及设置。联网语音可能将备注文本及相关请求数据发送给该引擎的服务提供者，适用该提供者的隐私政策。您可以在 Android 的文字转语音设置中查看或更换引擎和语音。Tingbo 不承诺所有设备上的朗读均为离线处理。Android 关于离线和联网语音的说明见 Voice API。

4. 系统备份与设备迁移

如果您启用了系统备份或设备迁移，Android 或设备厂商可能备份、传输或恢复符合其规则的应用数据，包括应用保存的文稿和偏好。该过程受系统版本、设备、账号及备份设置影响，与 Tingbo 的在线转换服务不同。请通过设备和备份服务的设置管理这些副本；参考 Android 自动备份说明。

5. 保留与删除

您可以从应用的文稿历史中删除已导入的文稿。该操作删除应用保存的对应文稿副本、编辑后的备注和历史记录，但不保证同时清除之前生成的所有朗读或导出缓存。

您可以通过 Android 的应用存储设置清理 Tingbo 的缓存或应用数据。已导出文件、其他文件服务中的原件及系统备份需要在对应位置单独管理。应用内删除文稿不会向在线转换提供者发送即时删除请求，供应商文件及日志按各自的留存规则处理。

如需了解数据处理方式或寻求删除方面的协助，请发送邮件至 m15568817011@163.com。请描述问题及必要的时间范围；无需在首次联系时附上完整文稿。我们会核实请求和实际可处理的数据范围，说明能够采取的措施。

6. 联系支持

如果您主动向上述邮箱发送支持或隐私请求，我们会收到您的邮箱地址、邮件内容以及您选择附上的资料，并使用这些信息处理请求。请避免发送与问题无关的个人信息。

7. 未成年人

Tingbo 面向 13 岁及以上用户，不面向 13 岁以下儿童。若您认为未满 13 岁的儿童向服务提交了个人信息，请联系上述邮箱，以便核实并处理。对未成年用户适用的监护要求仍以所在地区规定为准。

8. 数据安全与政策更新

在线转换方案采用 HTTPS 接口；这不代表端到端加密，也不代表转换服务无法读取待处理的文稿。文字转语音、设备备份及其他由您选择的系统服务还受各自的技术和隐私设置影响。

当应用功能或数据处理方式发生变化时，我们会更新本政策并标明生效日期。涉及需要额外告知或同意的数据处理变化时，会在适用的功能中另行提供说明。

9. 本网站

本政策网页托管于 GitHub Pages，标准连接日志按 GitHub 隐私声明处理。网站使用 Cloudflare Web Analytics 统计访问、来源和页面性能，不使用分析 Cookie 或跨网站追踪访客。这些统计针对网站访问，不收集文稿内容或应用播放事件。详见 Cloudflare Web Analytics 说明。
