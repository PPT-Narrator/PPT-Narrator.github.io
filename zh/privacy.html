隐私政策

最后更新：2026 年 9 月 22 日

概述

听播 Tingbo · PPT听稿（以下简称「本 App」或「我们」）是一款会逐页朗读演示文稿备注的应用，帮助你提前练习、熟悉讲稿。

我们非常重视你的隐私。本政策说明本 App 会收集哪些信息以及如何处理这些信息。听播 iOS 1.2 及以上版本在设备上渲染 PPT、PPTX 和 Keynote，不会为转换上传演示文稿。集成 Firebase 的 iOS 版本会使用 Firebase Analytics 了解功能使用情况；自定义统计事件不包含文件名或备注正文。

账号与统计数据

本 App 不需要注册账号。正常使用时，我们不要求你提供姓名、邮箱，也不请求通讯录或照片访问权限。若你主动联系我们，我们会收到你发送的信息。

在集成 Firebase 的 iOS 版本中，自定义统计事件不包含演示文稿内容、文件名或备注正文。Firebase Analytics 会处理使用事件及相关技术信息，详见下方说明。

在设备上处理

你的演示文稿和备注会在你自己的设备上处理。导入的演示文稿、幻灯片图片和备注会保存在本 App 的本地存储中，方便你随时重新打开。备注的朗读使用系统自带的文本转语音功能，在本机完成。

演示文稿渲染

听播 iOS 1.2 及以上版本在设备上解析、渲染 PPT、PPTX 和 Keynote（.key）。正常导入及重新打开历史记录不会将演示文稿上传到转换服务器。遇到无法本地渲染的文件，App 会提示错误，不会自动转交云端转换。

部分 Keynote 主题图片若未包含在文件中，App 可能按需从 iCloud 下载相应资源；这一过程不会上传你的演示文稿。导入的文件、幻灯片图片和备注仍保存在 App 本地。

第三方服务

听播 iOS 1.2 及以上版本的正常导入流程不使用 Cloudflare Worker 或 CloudConvert 转换文件。仅在需要补充 Keynote 主题资源时，App 可能从 iCloud 下载资源。我们不会出售或出租你的演示文稿与备注。

本网站托管在 GitHub Pages 上，GitHub 可能按照其隐私政策处理标准服务器日志，例如你的 IP 地址。

App 与官网统计

集成 Firebase 的 iOS 版本使用 Firebase Analytics 记录导入文件的格式与来源、渲染结果及耗时、页数、翻页和开始朗读等事件，不把文件名、演示文稿或备注正文写入这些自定义事件。Firebase 还可能自动收集应用事件和设备或应用实例标识。详情见 Firebase Analytics 事件说明及 Firebase 隐私说明。

本网站使用 Cloudflare Web Analytics 统计页面浏览量、访问次数、访问来源和页面性能。该服务不使用统计 Cookie，也不跨网站追踪单个访客。详情见 Cloudflare Web Analytics 说明。

官网统计与 App 的 Firebase Analytics 是两项独立服务；官网统计不会读取 App 中的演示文稿、备注或音频。

数据保留与删除

你导入的演示文稿保存在本 App 本地。你可以随时从历史记录中删除任何演示文稿。要删除所有数据，请卸载本 App，即可清除其本地存储的内容。

儿童隐私

本 App 不面向 13 岁以下的儿童，我们也不会在知情的情况下收集儿童的个人信息。

本政策的变更

我们可能不时更新本隐私政策。任何变更都会发布在本页面，并更新「最后更新」日期。变更生效后继续使用本 App 即表示你接受更新后的政策。
