iOS 隱私權政策

本政策說明聽播 iOS 版如何處理簡報、備註，以及官網造訪資料。

2026-09-22

1. 概述

聽播逐頁朗讀簡報備註。iOS 1.2 及以上版本在裝置上繪製 PPT、PPTX 和 Keynote，不會為轉換上傳簡報。整合 Firebase 的 iOS 版本使用 Firebase Analytics 了解功能使用情況；自訂統計事件不包含檔名或備註正文。

2. 我們不蒐集的資訊

無須建立帳號。一般使用時不要求姓名、電子郵件、聯絡資料、通訊錄或相片存取權，也不把簡報、檔名或備註正文寫入自訂統計事件。整合 Firebase 的版本由 Firebase Analytics 處理使用事件及相關技術資料。

3. 預設在裝置上處理

匯入的簡報、投影片圖片和備註儲存在 App 的本機空間。朗讀使用裝置內建的 iOS 文字轉語音功能。

4. 簡報繪製

iOS 1.2 及以上版本在裝置上匯入並繪製 PPT、PPTX 和 Keynote（.key）。一般匯入及重新開啟不會將簡報上傳至轉換伺服器；若無法在本機繪製，App 會顯示錯誤，不會自動交給雲端服務。

5. 第三方服務

部分未包含在 Keynote 檔案中的主題圖片可能按需從 iCloud 下載，但不會上傳你的簡報。iOS 1.2 及以上版本的正常匯入流程不使用 Cloudflare Worker 或 CloudConvert。網站由 GitHub Pages 託管，GitHub 可能依其隱私政策處理 IP 位址等標準連線紀錄。

6. App 與官網統計

整合 Firebase 的 iOS 版本使用 Firebase Analytics 記錄匯入格式與來源、繪製結果和耗時、頁數、翻頁及開始朗讀等事件；自訂事件不包含檔名、簡報或備註正文。Firebase 也可能自動收集 App 事件及裝置或 App 執行個體識別資訊。官網另以 Cloudflare Web Analytics 統計造訪和效能，不使用分析 Cookie 或跨網站個人追蹤；官網統計無法讀取 App 內的內容。

7. 保存與刪除

匯入的簡報留在 App 本機空間。你可以在歷史記錄中刪除個別簡報；解除安裝 App 可刪除其保存在裝置上的內容。

8. 兒童隱私

本 App 並非針對未滿 13 歲兒童提供，我們也不會在知情的情況下蒐集兒童個人資訊。

9. 政策變更

我們可能更新本政策，並在此頁標示新的更新日期。變更生效後繼續使用 App，表示你接受更新後的政策。
