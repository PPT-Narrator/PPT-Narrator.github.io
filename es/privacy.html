Política de privacidad de iOS

Cómo se tratan las presentaciones, las notas y las visitas a este sitio.

2026-09-13

1. Resumen

Tingbo lee las notas de cada diapositiva para facilitar el ensayo. La aplicación está diseñada para conservar presentaciones y notas en tu dispositivo; no recopilamos, vendemos ni compartimos información personal.

2. Datos que no recopilamos

No hace falta crear una cuenta. No recopilamos nombre, correo, contactos, ubicación, fotos, identificadores publicitarios, datos de seguimiento ni contenido de presentaciones y notas.

3. Tratamiento en el dispositivo

Las presentaciones importadas, las imágenes de diapositivas y las notas se guardan localmente. La lectura usa la función de texto a voz integrada en iOS.

4. Conversión de presentaciones

Para mostrar PPT o PPTX como imágenes, algunas versiones pueden convertir el archivo. Puedes usar un servicio de tu red local; cuando se necesita conversión remota, la versión de iOS descrita aquí crea el trabajo mediante Cloudflare Worker y sube directamente el archivo elegido a CloudConvert. Solo se usa para la conversión solicitada, no para publicidad ni perfiles personales.

5. Terceros

En la conversión remota, Cloudflare procesa la solicitud y CloudConvert recibe el archivo para generar el resultado. No vendemos ni alquilamos tus datos. GitHub Pages aloja el sitio y puede tratar registros de conexión, como la dirección IP, conforme a su política.

6. Analítica del sitio

Cloudflare Web Analytics mide visitas, procedencia y rendimiento sin cookies analíticas ni seguimiento individual entre sitios. Solo se aplica a la web: no añade analítica a la app ni envía presentaciones, notas o audio.

7. Conservación y eliminación

Las presentaciones permanecen en el espacio local de la app. Puedes borrar cada una en el historial; al desinstalar la app se elimina su contenido almacenado en el dispositivo.

8. Menores

La app no está dirigida a menores de 13 años y no recopilamos deliberadamente sus datos personales.

9. Cambios

Podemos actualizar esta política e indicar una nueva fecha. Si sigues usando la app tras la entrada en vigor, aceptas la versión actualizada.
