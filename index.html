Frequently asked questions

What is Tingbo?

Tingbo is a presentation rehearsal app. It displays each slide and reads its speaker notes aloud, helping presenters learn the order, wording, and key points before a report, lesson, meeting, or talk.

How do I make PowerPoint speaker notes read aloud?

Import a PPT or PPTX, go to the first slide, and tap Play. Tingbo reads the current slide's note and automatically moves to the next slide when narration finishes.

Does Tingbo support PPT, PPTX, and Keynote?

Tingbo imports PPT and PPTX files. For a Keynote .key file, open it in Keynote, export a PowerPoint copy, save the PPTX to Files, and import that copy into Tingbo.

Are presentation files uploaded to a server?

Image-based PPTX files can be read locally. Legacy PPT files and PPTX files with editable layouts may be uploaded only when a rendering conversion is required. The current iOS configuration requests a conversion job through a Cloudflare Worker, then uploads the selected file directly to CloudConvert. Imported history stays in the app, while speech playback uses the device's system text-to-speech engine. See the Privacy Policy for details.

Can I edit and export speaker notes?

Yes. Open the current slide's notes, edit the script, and save it for playback. You can export speaker notes as Markdown or export a PPTX copy from the app.

Can Tingbo play in the background or through headphones?

Yes. Background playback and headphone output are supported. Tingbo pauses automatically when headphones are disconnected.

Do I need an account?

No. Tingbo does not require registration or login.
