iOS 개인정보 처리방침

Tingbo iOS 앱과 웹사이트에서 발표 자료와 관련 정보를 처리하는 방법입니다.

2026-09-22

1. 개요

Tingbo는 발표자 노트를 슬라이드별로 읽습니다. 자료와 노트는 기기에 저장되지만 아래 설명한 변환 서비스를 이용할 때는 예외입니다. Firebase가 포함된 iOS 버전은 기능 사용 현황을 파악하기 위해 Firebase Analytics를 사용하며 맞춤 이벤트에 파일 이름이나 노트 본문을 포함하지 않습니다.

2. 수집하지 않는 정보

계정이 필요하지 않습니다. 일반적인 사용에서 이름, 이메일, 연락처나 사진 접근 권한을 요구하지 않습니다. 발표 자료, 파일 이름, 노트 본문은 맞춤 분석 이벤트에 포함하지 않습니다. 클라우드 변환 시 선택한 파일이 전송될 수 있으며 Firebase Analytics는 사용 이벤트와 관련 기술 정보를 처리합니다.

3. 기기 내 기본 처리

가져온 자료, 슬라이드 이미지, 노트는 앱의 로컬 저장소에 보관됩니다. 읽어 주기는 기기의 iOS 음성 합성 기능을 사용합니다.

4. 발표 자료 변환

PPT/PPTX를 슬라이드 이미지로 표시하기 위해 변환이 필요할 수 있습니다. 기본적으로 사용자의 로컬 네트워크에 있는 변환 서비스에 연결할 수 있습니다. 원격 변환이 필요하면 이 방침에 설명된 iOS 빌드는 Cloudflare Worker에서 작업을 만들고 선택한 파일을 CloudConvert로 직접 전송합니다. 파일은 요청한 변환에만 사용되며 광고나 프로파일링에 사용되지 않습니다.

5. 제3자 서비스

클라우드 변환 시 Cloudflare가 작업 요청을 처리하고 CloudConvert가 선택된 파일을 받습니다. 당사는 데이터를 판매하거나 대여하지 않습니다. 웹사이트는 GitHub Pages에 호스팅되며 GitHub가 IP 주소 등 일반적인 접속 기록을 처리할 수 있습니다.

6. 앱과 웹사이트 분석

Firebase가 포함된 iOS 버전은 Firebase Analytics로 가져오기 형식과 경로, 렌더링 결과와 시간, 슬라이드 수, 페이지 이동 및 읽기 시작 이벤트를 기록합니다. 맞춤 이벤트에 파일 이름이나 발표 자료 및 노트 본문은 포함하지 않습니다. Firebase는 자동 앱 이벤트와 기기 또는 앱 인스턴스 식별자를 수집할 수도 있습니다. 웹사이트는 별도로 Cloudflare Web Analytics로 방문과 성능을 측정하며 분석 쿠키나 사이트 간 개인 추적을 사용하지 않습니다. 웹사이트 분석은 앱의 콘텐츠에 접근할 수 없습니다.

7. 보관과 삭제

가져온 자료는 앱의 로컬 저장소에 남습니다. 기록에서 개별 자료를 삭제할 수 있으며, 앱을 제거하면 기기에 저장된 앱 데이터를 지울 수 있습니다.

8. 아동의 개인정보

앱은 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 방침 변경

방침을 변경할 때 이 페이지와 최종 수정일을 갱신합니다. 변경이 시행된 뒤 계속 사용하면 새 방침에 동의한 것으로 간주합니다.
